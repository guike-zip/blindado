Política de Privacidade do Blindado

Última atualização: 22 de setembro de 2026

Resumo em uma frase: o Blindado não coleta, não transmite e não armazena nenhum dado seu em servidor próprio — porque não existe servidor próprio. Não há backend.

O que o Blindado faz

O Blindado é um app pago de download único para iOS e macOS que configura DNS criptografado (DNS-over-HTTPS) em todo o sistema, usando a API nativa NEDNSSettingsManager da Apple, e oferece um bloqueador de conteúdo para o Safari baseado em uma lista estática de regras.

Dados que coletamos

Nenhum. O Blindado não pede cadastro, não usa conta, não tem SDK de análise (analytics) nem de anúncios, e não envia telemetria de nenhum tipo para nós ou para qualquer terceiro que não seja o provedor de DNS que você escolher.

Para onde vão suas consultas DNS

Para que seu iPhone ou Mac encontre um site, ele precisa fazer uma pergunta chamada consulta DNS. O Blindado configura o sistema para que essa pergunta saia criptografada, direto para o provedor de DNS que você escolher:

  • AdGuard DNS — política de privacidade do AdGuard DNS
  • Control D — política de privacidade do Control D
  • Ou um servidor DoH personalizado que você mesmo informar, no nível Personalizado — nesse caso, a política de privacidade de quem opera esse servidor é a que vale.

Quem responde essas consultas é o provedor escolhido, não o Blindado. Isso é inerente ao funcionamento de qualquer configuração de DNS e não constitui coleta de dados pelo Blindado.

Bloqueador de conteúdo do Safari

A extensão de bloqueio de conteúdo do Safari funciona inteiramente no seu dispositivo, a partir de uma lista de regras estática incluída no app. Ela não faz nenhuma chamada de rede, não envia URLs visitadas para lugar nenhum e não tem acesso ao conteúdo das páginas além do que a API SFContentBlockerManager da Apple permite (bloqueio declarativo por regra, sem execução de código nem leitura de conteúdo).

Tela "Testar"

A funcionalidade de teste faz requisições a uma lista fixa de domínios conhecidos (de anúncio/rastreamento e de controle) apenas para mostrar a você, localmente, se a proteção está bloqueando o que deveria. Nenhum resultado desses testes é enviado a servidor algum — o resultado só existe na tela do seu aparelho, na hora em que você roda o teste.

O que o Blindado NÃO faz

  • Não é uma VPN — não esconde seu IP nem troca sua localização.
  • Não bloqueia anúncios dentro de outros aplicativos (YouTube, Instagram, TikTok, jogos etc.) — atua no DNS do sistema e, no Safari, no bloqueador de conteúdo nativo.
  • Não guarda histórico nem estatísticas de navegação, nem para você, nem para nós.
  • Não usa cookies, pixels de rastreamento, identificadores de publicidade ou qualquer SDK de terceiros.

Crianças

O Blindado não é direcionado a crianças e não coleta, intencionalmente ou não, dados de nenhum usuário — inclusive menores de idade — pelas razões já descritas acima.

Alterações a esta política

Se esta política mudar, a nova versão será publicada nesta mesma página com a data de atualização revisada no topo. O uso do Blindado sempre foi, e continuará sendo, sem coleta de dados própria — mudanças aqui tendem a ser apenas de redação ou de provedores de DNS listados.
